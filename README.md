## Project Overview

This is my SQL project where I applied my SQL skills to clean and analyze data and identify meaningful, data-driven business insights.

The sample data used in this project includes product data, category data, customer data, and order details. I practiced basic MySQL concepts along with Joins, CTEs, CASE WHEN, WHERE, HAVING, and aggregation functions.

I identified key business insights by writing suitable SQL queries, such as monthly sales analysis, category distribution, customer analysis, and other important business metrics.

After completing this project, I gained more confidence in my SQL and analytical skills. I am now looking forward to an opportunity where I can apply these skills to solve real-world business problems and contribute to an organization.
